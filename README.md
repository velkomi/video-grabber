# VideoGrabber

VideoGrabber — локальное Windows-приложение с понятным интерфейсом для скачивания доступного видео и простого монтажа через FFmpeg.

## Возможности

- загрузка по ссылке через [yt-dlp](https://github.com/yt-dlp/yt-dlp);
- Deno и EJS для современной поддержки YouTube;
- выбор качества до 720p, 1080p, 4K или лучшего доступного;
- поддержка обычных страниц, прямых MP4, открытых HLS и DASH;
- локальный встроенный браузер, который может обнаружить открытый поток .m3u8 или .mpd;
- добровольное использование cookies из Chrome, Edge или Firefox только для текущей загрузки;
- отмена операции и понятный прогресс;
- быстрая обрезка и склейка через FFmpeg без изменения исходников;
- обязательная проверка результата через FFprobe;
- автономная сборка для Windows x64: .NET и Windows App SDK включены.

## Важные ограничения

Приложение не обходит DRM, платный доступ, шифрование или ограничения сайта. Оно предназначено только для материалов, которые вы вправе сохранять. Ни одна программа не может гарантировать скачивание «с любого сайта»: сайты меняют проигрыватели, авторизацию и протоколы.

Запись экрана отсутствует по замыслу проекта.

## Требования

- Windows 10 x64 версии 2004 (build 19041) или новее;
- Windows 11 x64 поддерживается;
- интернет для автоматической первоначальной установки медиакомпонентов.

## Запуск готовой сборки

1. Скачайте архив VideoGrabber-win-x64.zip из раздела Releases.
2. Распакуйте архив в обычную папку.
3. Запустите VideoGrabber.exe.
4. Вставьте ссылку и нажмите Скачать. При первом запуске VideoGrabber сам установит необходимые компоненты и продолжит загрузку.

Компоненты сохраняются в `%LocalAppData%\VideoGrabber\tools`. Их также можно вручную установить или обновить в разделе Компоненты. Установщик показывает SHA-256 и сверяет его с digest GitHub, когда он доступен.

Диагностический журнал находится в `%LocalAppData%\VideoGrabber\logs\startup.log`. URL целиком, cookies и токены в журнал не записываются.

## Сборка из исходников

Используется .NET SDK 10.0.400:

~~~powershell
$dotnet = 'D:\CODEX\Portable\dotnet-sdk-10\dotnet.exe'
& $dotnet restore .\VideoGrabber.slnx
& $dotnet build .\VideoGrabber.slnx -c Debug --no-restore
& $dotnet test .\VideoGrabber.slnx -c Debug --no-build
& .\scripts\Build-Release.ps1 -DotNet $dotnet
~~~

## Конфиденциальность

VideoGrabber работает локально. Проект не содержит аналитики и собственного сервера. Cookies не копируются в проект и не сохраняются приложением: при явном выборе браузера yt-dlp читает их на время операции. Диагностические строки очищаются от распространённых токенов и заголовков cookies.
