# VideoGrabber

VideoGrabber — приложение и веб‑сервис для скачивания доступного видео по ссылке, работы с курсами GetCourse и локальной обработки медиа.

> **Windows:** актуальную сборку можно скачать с официального сайта VideoGrabber:  
> https://videograbber.srv1902378.hstgr.cloud/download/windows

## Возможности

- обычные YouTube‑видео и YouTube Shorts;
- Instagram Reels и публичные видео;
- TikTok‑видео;
- Pinterest video Pins;
- другие сайты и прямые MP4/HLS/DASH‑потоки, которые поддерживает встроенный медиадвижок;
- выбор качества вплоть до лучшего доступного;
- скачивание через сайт без обязательного запуска Windows‑приложения;
- Windows‑клиент для локального скачивания, закрытых страниц, GetCourse и дополнительных инструментов;
- MP3, локальная транскрибация, обрезка и склейка видео;
- проверка готового результата через FFprobe;
- self‑contained Windows x64‑сборка со встроенными yt‑dlp, FFmpeg, FFprobe, Deno и Whisper.

Для публичных роликов авторизация не требуется по умолчанию. Cookies или вход используются только как дополнительный режим для действительно закрытого, приватного или возрастного контента, если площадка сама требует авторизацию.

## Важные ограничения

VideoGrabber не обходит DRM, платный доступ или шифрование и предназначен для материалов, которые пользователь вправе сохранять. Доступность конкретного ролика зависит от того, отдаёт ли площадка этот контент публично либо текущей авторизованной сессии.

## Требования для Windows

- Windows 10 x64 build 19041 или новее;
- Windows 11 x64 поддерживается;
- интернет‑соединение.

## Установка

1. Откройте официальный сайт VideoGrabber.
2. Нажмите **«Скачать Windows‑версию»**.
3. Распакуйте весь ZIP в отдельную папку, например `D:\VideoGrabber`.
4. Запустите `VideoGrabber.Managed.exe`.
5. Вставьте ссылку, выберите папку и нажмите **«Скачать»**.

Контрольная сумма текущего официального архива доступна по адресу:

https://videograbber.srv1902378.hstgr.cloud/download/windows/checksum

Проверить локальный ZIP можно командой:

~~~powershell
Get-FileHash .\VideoGrabber-Windows.zip -Algorithm SHA256
~~~

## Как пользоваться

### Обычное видео
Вставьте ссылку и нажмите **«Скачать»**. Для публичных YouTube / Shorts / Reels / TikTok / Pinterest вход по умолчанию не нужен.

### Через сайт
На сайте выберите **«В браузер — без приложения»**. Сервер подготовит файл и предложит его скачать браузером.

### Через Windows
Windows‑приложение удобно, если нужно сохранить файл сразу на компьютер, использовать локальную браузерную сессию или дополнительные функции.

### GetCourse
Разверните блок **«Дополнительные возможности»**, откройте курс во встроенном браузере, при необходимости войдите в свой GetCourse‑аккаунт и используйте **«Скачать весь курс»**.

### Закрытые страницы
Если сама площадка требует вход, выберите соответствующий способ входа/cookies или используйте встроенный браузер. Это fallback, а не обязательное условие для публичных роликов.

## Диагностика

Логи Windows‑клиента находятся в:

`%LocalAppData%\VideoGrabber\logs`

Полные cookies, токены и секреты в диагностические сообщения не должны попадать.

## Конфиденциальность

Локальные Windows‑загрузки сохраняются на компьютере пользователя. Серверный режим хранит промежуточный файл только столько, сколько требуется для выдачи результата и политики временного хранения.
