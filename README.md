# VideoGrabber

[![Сборка](https://github.com/velkomi/video-grabber/actions/workflows/build.yml/badge.svg)](https://github.com/velkomi/video-grabber/actions/workflows/build.yml)
[![Последний релиз](https://img.shields.io/github/v/release/velkomi/video-grabber?display_name=tag)](https://github.com/velkomi/video-grabber/releases/latest)
[![Лицензия MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

VideoGrabber — бесплатное локальное Windows-приложение с понятным светлым интерфейсом для загрузки доступного видео и простого монтажа через FFmpeg.

> **Готовая версия:** [скачать VideoGrabber для Windows x64](https://github.com/velkomi/video-grabber/releases/latest)

## Возможности

- загрузка по ссылке через [yt-dlp](https://github.com/yt-dlp/yt-dlp);
- Deno и EJS для современной поддержки YouTube;
- выбор качества до 720p, 1080p, 4K или лучшего доступного;
- поддержка обычных страниц, прямых MP4, открытых HLS и DASH;
- локальный встроенный браузер, который может обнаружить открытый поток .m3u8 или .mpd;
- добровольное использование cookies из Chrome, Edge или Firefox только для текущей загрузки;
- живой процент загрузки, скорость, оставшееся время и отмена операции;
- кнопка открытия папки загрузок и меню «Вставить» по правому клику в поле ссылки;
- быстрая обрезка и склейка через FFmpeg без изменения исходников;
- обязательная проверка результата через FFprobe;
- автономная сборка для Windows x64: .NET и Windows App SDK включены.

Fathom Video проверен вручную на открытой ссылке. YouTube, Rutube и другие сайты обрабатываются через актуальный `yt-dlp`; встроенный браузер помогает обнаружить открытые HLS/DASH-потоки, если обычный анализ страницы не сработал.

## Важные ограничения

Приложение не обходит DRM, платный доступ, шифрование или ограничения сайта. Оно предназначено только для материалов, которые вы вправе сохранять. Ни одна программа не может гарантировать скачивание «с любого сайта»: сайты меняют проигрыватели, авторизацию и протоколы.

Запись экрана отсутствует по замыслу проекта.

## Требования

- Windows 10 x64 версии 2004 (build 19041) или новее;
- Windows 11 x64 поддерживается;
- интернет для автоматической первоначальной установки медиакомпонентов.

## Установка на другой компьютер

1. Откройте [последний релиз](https://github.com/velkomi/video-grabber/releases/latest).
2. Скачайте архив `VideoGrabber-win-x64-v0.1.8.zip`.
3. Распакуйте **весь архив** в обычную папку, например `D:\VideoGrabber`.
4. Запустите `VideoGrabber.exe`. Установка .NET отдельно не требуется.
5. Вставьте ссылку, выберите папку и нажмите **Скачать**. При первой загрузке приложение само предложит установить медиакомпоненты.

Windows может показать предупреждение SmartScreen, потому что EXE пока не подписан платным сертификатом. Проверьте, что архив скачан именно из этого репозитория, затем выберите «Подробнее» → «Выполнить в любом случае».

Проверить целостность архива можно файлом `.sha256.txt` из релиза или командой:

~~~powershell
Get-FileHash .\VideoGrabber-win-x64-v0.1.8.zip -Algorithm SHA256
~~~

Для версии `v0.1.8` ожидается SHA-256:

~~~text
FB7A356B30C10329BCCB4201CBC7C64366EE9A9BB4BBC0B7887CF974C565700B
~~~

Компоненты сохраняются в `%LocalAppData%\VideoGrabber\tools`. Их также можно вручную установить или обновить в разделе Компоненты. Установщик показывает SHA-256 и сверяет его с digest GitHub, когда он доступен.

Диагностический журнал находится в `%LocalAppData%\VideoGrabber\logs\startup.log`. URL целиком, cookies и токены в журнал не записываются.

## Как пользоваться

1. На вкладке **Загрузчик** вставьте адрес страницы или прямого потока.
2. Выберите качество и, при необходимости, cookies браузера для страницы, где вы уже вошли в аккаунт.
3. Нажмите **Скачать** и дождитесь статуса «Готово». Во время передачи отображаются процент, скорость и примерное оставшееся время.
4. Нажмите **Открыть папку загрузок**, чтобы увидеть сохранённый файл.
5. На вкладке **Редактор** можно обрезать ролик или объединить несколько совместимых файлов.

Если анализ страницы длится необычно долго, обновите компоненты, попробуйте cookies своего браузера или кнопку встроенного браузера. Для прямых открытых потоков поддерживаются, в частности, `.mp4`, `.m3u8` и `.mpd`.

## Обновление

Скачайте новый ZIP из [Releases](https://github.com/velkomi/video-grabber/releases), распакуйте его в новую папку и запустите новый EXE. Локальные медиакомпоненты и журналы находятся отдельно в `%LocalAppData%\VideoGrabber`, поэтому при замене папки программы не теряются.

## Копирование исходников

~~~powershell
git clone https://github.com/velkomi/video-grabber.git
cd video-grabber
~~~

## Сборка из исходников

Используется .NET SDK 10.0.400:

~~~powershell
$dotnet = 'D:\CODEX\Portable\dotnet-sdk-10\dotnet.exe'
& $dotnet restore .\VideoGrabber.slnx
& $dotnet build .\VideoGrabber.slnx -c Debug --no-restore
& $dotnet test .\VideoGrabber.slnx -c Debug --no-build
& .\scripts\Build-Release.ps1 -DotNet $dotnet
~~~

Готовый архив появится в `artifacts\release-0.1.8`. В GitHub Actions используются стандартные публичные Windows-runner'ы; сборка запускается для `main`, pull request и вручную, но не повторяется отдельно для тега того же коммита.

## Структура проекта

- `src/VideoGrabber.App` — интерфейс WinUI 3;
- `src/VideoGrabber.Core` — модели и контракты;
- `src/VideoGrabber.Infrastructure` — интеграция с yt-dlp, FFmpeg и процессами;
- `tests` — модульные и интеграционные тесты;
- `scripts` — установка компонентов и выпуск переносимой сборки.

Архитектура подробнее описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Если что-то не работает

- сначала откройте **Компоненты** и нажмите **Установить или обновить**;
- убедитесь, что ссылка открывается в обычном браузере и видео доступно вашему аккаунту;
- попробуйте вход через cookies Chrome, Edge или Firefox;
- приложите к GitHub Issue описание шага и очищенный журнал `startup.log`, но не публикуйте персональные ссылки, cookies или токены.

## Конфиденциальность

VideoGrabber работает локально. Проект не содержит аналитики и собственного сервера. Cookies не копируются в проект и не сохраняются приложением: при явном выборе браузера yt-dlp читает их на время операции. Диагностические строки очищаются от распространённых токенов и заголовков cookies.
