Один маршрут

Сайт управляет очередью. Windows скачивает.

1

Войдите

Google или подтверждённый e-mail связываются с одним VideoGrabber account.

2

Вставьте ссылку

Выберите видео, MP3 или полный курс и нужное качество.

3

Компьютер заберёт job

Зарегистрированный VideoGrabber проверяет подпись устройства и получает только своё задание.

4

Результат остаётся локально

Видео и курсы не становятся постоянным облачным архивом VideoGrabber.
