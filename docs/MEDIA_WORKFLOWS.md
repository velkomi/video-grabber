# VideoGrabber 0.1.10-preview.2

Предварительная версия: новые функции проверены, но не все внешние сайты доступны для проверки.
Стабильная папка v0.1.9 не заменяется; текущие изменения находятся в feature/media-workflows-20260912.

## Использование
1. Вставьте ссылку и нажмите «Скачать». Для звука включите «Скачать MP3».
2. В карточке «Звук и текст» можно выбрать локальный файл, извлечь MP3 или получить TXT + SRT.
3. В «Компоненты» укажите whisper-cli.exe и многоязычную модель ggml-base.bin; нажмите «Сохранить настройки».
4. Для закрытого урока откройте ссылку во встроенном браузере и войдите на самом сайте. Пароль не вводится в настройки VideoGrabber.
5. Запустите видео, выберите найденный поток. Для передачи сессии явно выберите «Встроенный браузер — только эта загрузка».
6. После загрузки разрешение на использование встроенной сессии сбрасывается. Кнопка закрытия браузера очищает cookies.
7. В «Компоненты» выбираются полный или расширенный режим журналов; сохраните настройки, чтобы сохранить выбор между запусками.
8. Там же формируется отчёт за сутки, 7 или 30 дней. Кнопка расписания создаёт локальные задачи только по вашему нажатию.

## Границы
Программа не обходит DRM и ограничения прав доступа. Авторизация не гарантирует возможность сохранения любого урока.
Водяные знаки, уже находящиеся в кадрах, не удаляются. Расшифровка требует проверки человеком.
Модель Whisper устанавливается отдельно, не входит в переносимый ZIP. Облачного распознавания нет.
Для iglyrazuma.ru наблюдались Timeout/ConnectionAborted; реальное скачивание закрытого урока не подтверждено.
Telegram-отправка и автоматическое исправление кода не включены. Отчёты — сводки событий, а не заключения ИИ.
При включённом расписании компьютер и пользовательская сессия Windows должны быть доступны.

## Диагностика
Журналы: %LOCALAPPDATA%\VideoGrabber\logs\vg-*.jsonl. Срок до 30 дней, файл до 2 МБ, суммарно до 32 МБ.
Отчёты: %LOCALAPPDATA%\VideoGrabber\reports. Сводка JSON/Markdown и отдельное безопасное задание Codex.
Команды: scripts/Analyze-Logs.ps1 -Period daily (также weekly/monthly); scripts/Install-DiagnosticsTasks.ps1 -WhatIf.
Для Telegram используется явный -SendTelegram и отдельные переменные VIDEOGRABBER_TELEGRAM_BOT_TOKEN / VIDEOGRABBER_TELEGRAM_CHAT_ID; не храните их в Git.
Доказательства разработки: artifacts/upgrade-20260912; актуальная контрольная точка: docs/UPGRADE_CHECKPOINT.md.
