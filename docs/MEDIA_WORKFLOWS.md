# VideoGrabber 0.1.10-preview.20

Предварительная версия: функции проверены автоматическими тестами и packaged UI smoke; закрытый GetCourse требует финального живого acceptance.
Стабильная папка v0.1.9 не заменяется; текущие изменения находятся в feature/media-workflows-20260912.

## Использование
1. Вставьте ссылку и нажмите «Скачать». Для звука включите «Скачать MP3».
2. Для закрытого GetCourse откройте ссылку во встроенном браузере и войдите на самом сайте; пароль VideoGrabber не читает и не сохраняет.
3. Дождитесь списка «Видео 01, Видео 02…». Для найденного master запускать ролик вручную не требуется.
4. Выберите качество: Лучшее, до 4K/1080p/720p/480p/360p. Перед загрузкой child-HLS автоматически проверяется на отсутствие шифрования.
5. Нажмите «Скачать выбранное видео» или «Скачать все найденные». Для batch выбранная сессия применяется ко всей очереди и сбрасывается после неё.
6. Если master не найден, запустите видео на несколько секунд для резервного обнаружения media-потока.
7. В «ⓘ Информация» доступны инструкция, версия, автор и тема «Как в Windows / Светлая / Тёмная».
8. В карточке «Звук и текст» можно выбрать локальный файл, извлечь MP3 или получить TXT + SRT; Whisper работает локально.
9. После успешной загрузки рядом с браузерными действиями становится доступна кнопка «Транскрибировать скачанное» — она подставляет последний готовый файл в локальный Whisper-процесс.
10. На странице GetCourse-тренинга кнопка «Скачать весь курс» считывает доступные подтренинги/модули и уроки, создаёт дерево папок «Курс → 01 - Модуль → видео» и скачивает уроки по порядку. Повторный запуск пропускает уже готовые файлы.

## Границы
Программа не обходит DRM, ключи шифрования и ограничения прав доступа. Зашифрованный HLS блокируется fail-closed.
Авторизация не гарантирует возможность сохранения любого урока. Водяные знаки в кадре не удаляются.
Kinescope и HLS/DASH/MP4 поддерживаются только там, где поток доступен пользователю и не защищён DRM.
Тема встроенной страницы сайта определяется самим сайтом; VideoGrabber не перекрашивает чужие страницы и плееры.
Для iglyrazuma.ru подтверждены scoped routing, воспроизведение и обнаружение master/media HLS; preview.10 должен подтвердить master-download без Play на реальных шести видео.

## Диагностика
Журналы: %LOCALAPPDATA%\VideoGrabber\logs\vg-*.jsonl. Срок до 30 дней, файл до 2 МБ, суммарно до 32 МБ.
Отчёты: %LOCALAPPDATA%\VideoGrabber\reports. Сводка JSON/Markdown и отдельное безопасное задание Codex.
Команды: scripts/Analyze-Logs.ps1 -Period daily (также weekly/monthly); scripts/Install-DiagnosticsTasks.ps1 -WhatIf.
Для Telegram используется явный -SendTelegram и отдельные переменные VIDEOGRABBER_TELEGRAM_BOT_TOKEN / VIDEOGRABBER_TELEGRAM_CHAT_ID; не храните их в Git.
Доказательства разработки: artifacts/upgrade-20260912; актуальная контрольная точка: docs/UPGRADE_CHECKPOINT.md.


## Быстрая обрезка и склейка
Быстрая обрезка использует stream copy без перекодирования. Диапазон должен полностью находиться внутри подтверждённой FFprobe длительности исходника; запрос за конец файла отклоняется до запуска операции.
Из-за расположения ключевых кадров фактическая граница быстрой обрезки может иметь небольшую GOP/keyframe-погрешность; после обработки VideoGrabber проверяет потоки и допустимый диапазон длительности до выдачи готового файла.
Быстрая склейка без перекодирования разрешена только для файлов с совместимой упорядоченной структурой потоков: codec/type, видео resolution/pixel format/time base и аудио sample rate/channels/time base должны совпадать. Несовместимые файлы требуют явного перекодирования вне этой операции и не склеиваются автоматически.

## Продолжение большого курса после перезапуска
Полный GetCourse-архив хранит `VideoGrabber.course.json` в корне. Файл записывается атомарно после каждого полностью завершённого урока. Для каждого видео используется стабильная `.vg-job-<resumeKey>` папка и `yt-dlp --continue`, поэтому после сбоя питания или перезагрузки сохранённый `.part/.ytdl` может быть продолжен.

После обычной перезагрузки: запустите VideoGrabber, откройте GetCourse во встроенном браузере и войдите, нажмите «Продолжить / открыть папку курса», выберите корневую папку курса с `VideoGrabber.course.json`, затем продолжите. Завершённые уроки пропускаются, незавершённые проверяются и докачиваются.

Для архива, созданного preview.19 и старше, state-файла ещё нет. Один раз откройте исходную страницу курса во встроенном браузере, войдите, нажмите «Продолжить / открыть папку курса» и выберите существующую папку `… - Полный архив`. VideoGrabber перечитает только структуру курса, создаст `VideoGrabber.course.json`, сопоставит уже имеющиеся файлы и не будет заново скачивать готовые MP4/PDF/DOCX/изображения. Старые случайные `.vg-job-*` с partial-файлами будут мигрированы в стабильные resume-папки при обработке соответствующего видео.

Если CDN GetCourse временно отвечает `fragment 1 not found`, видео не считается завершённым: приложение обновляет подписанный master и повторяет загрузку до четырёх раз. При исчерпании попыток урок остаётся незавершённым и снова попадёт в следующий запуск «Продолжить».
