# VideoGrabber: media workflows and diagnostic acceptance plan

Goal: extend the existing Windows app, preserving working v0.1.9, its light UI, author credit, and live progress.
Architecture: reuse yt-dlp + FFmpeg + WebView2; small separate services, no replacement application, no cloud backend.
Baseline: daea5d419c568d4a608a1f8f95b495a6f8b62825; 21 tests pass on the actual Windows PC.
Work: existing isolated worktree, branch feature/media-workflows-20260912. Never publish, push, or overwrite installed v0.1.9.

## Eight acceptance blocks
1. Downloads: preserve --progress with --print; finite retries; cancellation; validate actual output with FFprobe; no false success for missing/empty media.
2. MP3: AudioOnly produces actual .mp3 with audio codec mp3, not renamed video; local file conversion available after download; never overwrite source.
3. Transcription: local whisper.cpp CLI adapter with explicit model/executable paths; export TXT and SRT; clear missing-model/no-audio/cancel errors; no silent cloud upload.
4. Browser session: user signs in on the real site in WebView2; explicit per-download consent; only URI-matching cookies in temporary user-only file; erase after process ends; no password capture.
5. Media discovery: retain original lesson URL, list selectable MP4/HLS/DASH candidates detected by URL or MIME; avoid replacing text repeatedly; include necessary source Referer; no DRM/key extraction.
6. Safety: redact complete Cookie, Authorization, passwords, signed query values and private URL identifiers from persistent diagnostics. Do not destroy machine-readable process output before parsing it. Protect concurrent jobs and original files.
7. Logging: full normal mode and expanded debug mode; structured JSONL with timestamps, job/process correlation IDs, stage, result, duration, exit code; normal avoids per-line noise, debug captures sanitized output. Rotation + total size cap + maximum 30 days; report write failures visibly.
8. Diagnostics: offline deterministic daily/weekly/monthly reports, explicit no-data states, safe Codex handoff document and optional Telegram transport OFF without configured destination. No automatic production patching/publishing. Per-module smoke results retained.
