## Бесплатные варианты

Не требуется покупать «коммерческую лицензию FFmpeg» для выполнения GPL/LGPL-условий: проект таких альтернативных лицензий не предлагает. Текущие инструменты можно использовать на условиях их действующих лицензий, выполнив обязательства по распространению. Собственный MIT-код может распространяться отдельно, и платный доступ к функциям сервиса сам по себе не отменяет MIT/GPL-права на полученные копии кода.

Вариант с LGPL-сборкой нужно сначала проверить на необходимых кодеках и редакторе; отсутствиеlibx264/libx265 влияет на доступные энкодеры. Он тоже требует соблюдения LGPL и соответствующих исходников. Замена «потому что бесплатный» без функциональных тестов не выполняется.

Другой вариант — отдельная установка официальных утилит напрямую от upstream вместо распространения наших копий в Setup/ZIP. Для этого нужны отдельный проверенный downloader, пин версии/хэша, notices, восстановление после сбоя и удобный первый запуск. Это изменение сборки/UX, а не формальная замена текста; оно пока не внедрено. Не считать статусpreview или бесплатную раздачу освобождением от лицензионных условий.

Итог: **NOTICE_PACKAGE_IMPROVED; COMMERCIAL_REDISTRIBUTION_GATE_NOT_CLOSED**. Финальный пакет не объявляется готовым к коммерческому распространению по одному только новому списку лицензий.
