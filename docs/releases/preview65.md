# VideoGrabber preview.65 — имена файлов и восстановление сессии

Дата: 10 октября 2026. Подготовка Windows-пакета.

- Обычное видео сохраняется с читаемым названием без автоматического ID источника и суффикса длительности. Косые черты, включая Unicode, заменяются на тире. Существующие ограничения длины, имён Windows и защита от перезаписи сохранены.
- После ошибки или отмены удаляется только пустая временная папка, созданная данным заданием. Папка с файлами сохраняется для восстановления; внешние пути и reparse points не удаляются.
- Ответ 401/403/404 на запрос desktop challenge запускает предусмотренное обновление сессии вместо бесконечного повторения ошибочного запроса. Это не устраняет зависимость браузерной авторизации от доступности внешнего провайдера и не меняет VPN/маршруты компьютера.
- Сообщение ошибки Rutube объясняет возможное влияние региона и VPN; это не заявление, что VPN обязательно является причиной каждого 404.

Проверки инфраструктуры: 741 успешная, 14 интеграционных пропущены, ошибок нет. Проверены граничные имена, изоляция заданий, сохранение непустых папок и обработка challenge. Настоящий ранее скачанный файл переименован: размер 696855607 байт, контрольные суммы до/после совпали. Старая пустая папка не удалялась без отдельного разрешения.

Собран локальный Managed-пакет с source commit `972028d8c8ef97a129f10b8ffa650b1490233bd5`. После штатного запроса Windows администратора обновлены 11 собственных файлов установленного клиента. ProductVersion содержит preview.65 и этот commit; контрольная сумма каждого обновлённого файла совпала. Настройки и медиаутилиты не заменялись. Повторный интерактивный вход и скачивание через GUI новой версии пока не проверены. Это проверенная замена собственных файлов, а не подтверждение нового полного публичного установщика.
