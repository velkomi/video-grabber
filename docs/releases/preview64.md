## Опубликовано

Центр /info/ содержит8 страниц: помощь, условия, данные, отдельное добровольное согласие, подписка/отмена/возврат, рефералка, компоненты/лицензии, контакты. В контактах оригинальный Telegram-значок, почта владельца и проверенная личная визитка. Web/Mini App получили ссылки, Windows — раскрывающийся блок справки и постоянную ссылку контактов. Отдельного партнёрского раздела нет.

Принятия/отзывы и текстовые версии хранятся в append-only журнале/архиве. SHA-256 вычисляется из компактной сериализации документа, независимо от LF/CRLF/отступов. Клиент не подставляет свой текст/хэш. Для курса подтверждение относится к конкретному intent; проверки есть в /jobs и /reservations. Native обновляет сессию перед записью, Web блокирует параллельную отправку; старая галочка не даёт два разных курса. Согласия старым аккаунтам не приписываются. Рекламная рассылка не запускается.
