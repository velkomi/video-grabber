# VideoGrabber 0.1.10-preview.61-rc.1

Общий Studio-интерфейс сайта, Windows и Telegram Mini App. Windows сохраняет действующую сессию при ошибке отдельного offline lease; официальный значок Telegram и полный ник разработчика помещаются в боковой карточке. Бот предоставляет меню, привязку общего аккаунта и отправку поддерживаемого готового MP4 в диалог с подписью. WebGL восстанавливается после потери контекста либо показывает резервное изображение.

## Проверка и выпуск

Результаты сборки, тестов, хеши пакетов, GitHub commit и публичные загрузки фиксируются в отчёте владельца после окончания выпуска. Предыдущий серверный снимок проверен 382 platform-тестами и 34 сценариями публичного интерфейса. Это отдельные свидетельства, они не заменяют свежие проверки новой Windows-сборки и GitHub CI.

Локальные проверки выпуска: Core, Infrastructure, Worker, web unit, диагностика, настройка Telegram и HTTP smoke. Визуальный QA реального WinUI проверяет пять страниц при шести размерах окна, полный ник, фирменный значок и доступность ссылки. Необязательные тесты с внешними авторизованными источниками/образцами речи требуют отдельной среды и учитываются как пропуски.

## Ограничения

- Preview-выпуск, цифровая подпись EXE отсутствует.
- Новый интерактивный Google-вход, отправка реального пользовательского видео через Telegram и личный профиль Comet требуют ручной приёмки. Восстановление существующей Windows-сессии проверено отдельно.
- Прямой MP4 для Telegram ограничен 20 MiB и доступностью источника для Telegram. Обработка остальных источников выполняется на компьютере пользователя.
- Удаление старых релизов на VPS не удаляет рабочую БД, конфигурацию, действующие образы и локальные резервные копии владельца.
