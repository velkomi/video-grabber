## Безопасность развёртывания и откат

До миграции создана PostgreSQL-копия, проверены читаемость архива и SHA-256. Предыдущие настройки, образ API и файлы download сохранены. 48 соседних контейнеров, включая worker, не пересоздавались. Режим media storage остался `client_only`; в worker jobs нет медиафайлов.

Первая сборка migrator обнаружила несовпадение старых миграционных хэшей из-за Windows CRLF. Проверены все ранее записанные миграции: они совпали с Git blobs LF. Серверный архив пересобран через `git -c core.autocrlf=false -c core.eol=lf archive`; проверка хэшей не ослаблялась, сохранённая история не переписывалась. Две неуспешные попытки не применили новые миграции; каноническая сборка завершила 064/065 штатным migrator.

Для отката приложения сохраняются предыдущий image/config и download-файлы. Новые финансовые таблицы и историю при откате не удалять. Для остановки новых скидочных операций достаточно выключить флаг, сохранив обработку уже созданных счетов/возвратов.

## Ограничения

- Computer Use остановлен владельцем физической клавишей Esc. Финальная визуальная проверка установленного окна не завершена; совпадение файлов, версия, сохранённая сессия и серверные операции проверены отдельно.
- Новый интерактивный вход через Google/e-mail не выполнялся; проверена существующая сессия. Доставка настоящего видео ботом и реальное платёжное списание не входили в эту проверку.
- Рабочий каталог содержит RUB-тарифы 1500/2500/5000. Цены Telegram Stars пока не заданы; UI и отдельный бонусный учёт XTR реализованы, но Stars checkout не объявляется настроенным.
- Установщик не подписан цифровым сертификатом. Человеческая приёмка нового интерфейса ожидается.
