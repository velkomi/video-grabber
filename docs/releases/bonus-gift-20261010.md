# Подарок в кабинете VideoGrabber

В «Приглашения и бонусы» добавлен крупный синий 3D-подарок с серебристой лентой и выпуклым знаком PLAY. На компьютере модель справа от данных, на телефоне — под текстом. Геометрия использует существующий единственный Three.js renderer. Без WebGL/при reduced motion показана собственная SVG-иллюстрация; она не считается живой 3D-моделью.

Изменены shared promotions markup/styles (подарок включается только web-атрибутом), web story stage, Three.js source/bundle, собственный SVG, cache URLs и web regression tests. Исправлено обнуление непрозрачности повторно используемых материалов при подготовке fade-переходов. Числа/ссылки/правила бонусов, платежи и аккаунты не менялись.

Проверено:63 web tests, JS syntax, сборка esbuild0.28.2 с existing Three0.186.1, реальные desktop/mobile рендеры и reduced-motion fallback. Тесты покрывают позднее появление карточки после входа, её исчезновение после выхода и общий material fade. Локальный визуальный preview явно помечен тестовым профилем; данные не поступают в production.

Владелец: @Velkoshkin. Изменения и проверка: Codex. Изображения и геометрия оригинальные, без новых зависимостей. Для проверки на сайте: обновить страницу, открыть кабинет и прокрутить к «Приглашения и бонусы».
