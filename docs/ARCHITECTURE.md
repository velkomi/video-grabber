# Архитектура

- VideoGrabber.App — WinUI 3, навигация, диалоги выбора файлов и WebView2.
- VideoGrabber.Core — модели, контракты, проверка URL и очистка диагностических данных.
- VideoGrabber.Infrastructure — безопасный запуск процессов, адаптер yt-dlp и редактор FFmpeg.
- scripts — аудит окружения, установка компонентов и воспроизводимая release-сборка.
- tests — изолированные тесты политик и поиска portable-компонентов.

Основной путь загрузки: URL → проверка → yt-dlp → FFmpeg → итоговый файл. Встроенный браузер лишь обнаруживает открытые HLS/DASH URL и не экспортирует сессионные данные.
